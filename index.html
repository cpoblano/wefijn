Simple 2D Platform Fighter (Demo)

Player 1 
Move: A / D
Jump: W (double jump enabled)
Attack: S
Player 2 
Move: ← / →
Jump: ↑ (double jump enabled)
Attack: ↓
Notes 
First to reduce opponent to 0 health wins; press R to restart.
New moves: double jump and aerial attacks — down-air (hit while falling) performs a downward slam.
Controls are positioned to the side to prevent page scroll when pressing arrow keys.
Troubleshooting 
If nothing appears: run a local server (python -m http.server) and open http://localhost:8000
If errors appear, a diagnostic box will show at the bottom with the stack trace.
