Simple 2D Platform Fighter (Demo)

Player 1 
Move: A / D
Jump: W
Attack: S
Player 2 
Move: ← / →
Jump: ↑
Attack: ↓

Open index.html in a browser (or run a local static server) to play. First to reduce opponent to 0 health wins; press R to restart.

If you see a diagnostic box at the bottom, it means the game threw an error — please paste the text here and I'll fix it.
